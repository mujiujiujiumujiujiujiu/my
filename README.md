# 梗战争模拟器

一个零依赖、原生 WebGL2 的俯视角梗战争自动战斗原型。战斗结构参考《How Many Dudes?》的“构筑队伍、连续敌群、自动模拟”节奏；玩家只负责预算与布阵，单位会自动寻敌、攻击、释放技能。角色卡头像和战斗单位共用原创水彩墨线图集，战场使用同笔触的水彩分区底图。

## 运行

最简单的方式：双击项目根目录里的 `index.html`，现代浏览器会直接加载静态内嵌数据并启动游戏，无需 Node.js。

如果修改了 `data/*.json`、`styles.css` 或 `src/*.js`，先运行一次 `npm run build`，它会把最新数据、样式、运行代码和图集写入 `index.html`，保证双击入口和 GitHub Pages 使用同一份内容。

提交整个项目目录到 GitHub 后，在仓库的 `Settings → Pages` 中选择目标分支和根目录，即可通过 `https://<用户名>.github.io/<仓库名>/` 打开游戏。GitHub 的 `github.com/.../blob/.../index.html` 文件预览页不会执行网页，需要使用 GitHub Pages 地址。

开发时也可以双击 `PLAY_GAME.cmd`，它会启动本地服务并打开系统默认浏览器。

```powershell
cd "C:\Program Files (x86)\Steam\s\steamapps\common\Blender\meme-war-sim"
npm run check
npm run build
npm run start
```

手动启动后打开 `http://127.0.0.1:4173`。启动脚本使用 Node.js 内置 HTTP 服务，不需要 Python。项目不依赖 Pixi、Three、Matter 或远程 CDN：画面由 WebGL2 着色器直接绘制，战斗碰撞使用项目内的轻量圆形刚体解算，方便离线运行和继续扩展。

## 操作

- 准备阶段：点击左侧纵向兵种卡，再点击战场左半区部署；也可以直接把兵种卡拖到左半场。
- 电脑与手机：左侧部署栏支持上下拖动/触控滑动；卡片可拖到战场部署，已部署单位拖回任意兵种卡即可撤销并全额退款。
- 右键玩家单位：撤回并返还费用；拖拽可调整位置。
- `开始战斗`：锁定部署并观看自动战斗。
- 每关敌方编队一次性全员入场；清空整场后进入结算并可前往下一关。
- 战斗阶段：空格暂停；`1 / 2 / 4` 切换倍速；按住 `G` 或鼠标左键进入慢动作。
- 鼠标拖拽平移镜头，滚轮缩放。
- 右上角可切换 10 个关卡，`再来一次` 会保留当前关卡并清空部署。
- 传送、突进、冲锋、召唤和延迟爆发都有对应落点、轨迹/脉冲和短标签；14 类攻击/技能各自使用程序化手绘 VFX，死亡采用温和的碎片淡出；角色本体不再挂永久圆环或朝向线，朝向只用于有侧向道具角色的水平翻转。

## 当前切片

移动端布局将右侧说明 UI 移除，顶栏保留紧凑的剩余预算与 1×/2×/4× 速度按钮；手机首屏以内嵌轻量图集、压缩底图和 low DPR 进入，不再后台请求高清图，桌面设备才在空闲时补载高清资源。

- 10 个数据驱动关卡，12 个可部署梗单位 + 1 个路障 + 敌方专属瓜摊老板。
- 预算、费用、部署区限制、撤回退款、敌我存活计数。
- 10 个数据驱动关卡均为单场全员敌群；单位从开战起同时进入战场，清空整场后才算通关。
- 最近目标 / 远程优先、近战与远程攻击、投射物、击退、眩晕、减速、嘲讽、治疗、冲锋、AOE、召唤和延迟标记；蔡徐坤投掷篮球，华强使用霰弹轨迹，嘎子使用狙击弹，大运/牛来冲撞，奶蛙投奶泡，黄色袋鼠投外卖，瓜摊老板投西瓜。
- 单位头顶血条、延迟扣血层、伤害/治疗数字、前摇/出手动作、命中火花、受击抖动/闪白、击退方向线、角色差异化技能/死亡特效、入场/生成/传送/冲锋/召唤/延迟爆发特效、上下文标签、事件播报、战斗倍速和结算评级。
- 13 个原创水彩墨线角色头像；远程、召唤和辅助单位会保持安全距离，敌人贴近时主动后撤。技能已经按最新 14 张参考图重构为篮球节奏、霰弹压制、狙击点名、卡车冲阵、狗叫嘲讽、耄耋召唤/W 嘴、妙脆角猫瞬移、奶泡治疗、外卖延迟、企鹅控制和刀盾反伤等差异化行为。
- 角色卡与战斗场景使用同一套 4 × 4 手绘 WebGL 图集，敌方瓜摊老板也有独立角色格；检索到的网络图片只用于提取“黑衣瓜摊、篮球/鸡、刀盾、黄袋鼠、企鹅”等稳定语义，不直接复用原图。
- 华强、嘎子等具有明显侧向道具的角色在数据中声明图集原始朝向，战斗中根据移动/攻击方向自动水平翻转；正面角色保持原始构图，避免无意义镜像。兵种卡会显示技能摘要，模拟器用统一动作状态承接所有技能反馈。

## 目录

- `index.html`：页面结构与 UI 入口。
- `src/webgl.js`：原生 WebGL2 渲染器、相机投影和战场绘制。
- `src/sim.js`：与画面无关的战斗模拟、技能、碰撞和胜负结算。
- `src/main.js`：输入、场景切换、UI、音效反馈和主循环。
- `data/units.json`：单位数值与技能数据源。
- `data/levels.json`：关卡预算、敌方编队和提示。
- `assets/units-handdrawn-atlas.png`：4 × 4 高清手绘角色图集；索引说明见 `assets/ASSET_NOTES.md`。
- `assets/units-handdrawn-atlas-low.png`：手机首屏使用的 50% 轻量角色图集。
- `assets/battlefield-watercolor-bg.png`：与角色图集匹配的高清 WebGL 水彩战场底图。
- `assets/battlefield-watercolor-bg-low.jpg`：手机首屏使用的压缩水彩底图。
- `scripts/check-data.mjs`：无依赖数据与语法检查。
- `scripts/check-balance.mjs`：固定种子基准编队烟测，确保每关可在预算内完整清场。
- `scripts/build-static.mjs`：将数据、样式、运行代码和轻量图集构建进 `index.html`，并检查静态入口是否过期。
- `scripts/check-static-runtime.mjs`：防止可选纹理再次阻塞静态入口启动。
- `PLAY_GAME.cmd`：Windows 双击启动入口。
- `scripts/launch.mjs`：启动服务器、等待端口就绪并打开浏览器。

这是原型阶段的可玩切片，尚未包含存档、联网、逐帧骨骼动画和商用音频；当前动作表现由原生 WebGL 几何特效与图集角色组合完成。移动端先以内嵌轻量图集、低 DPR/低特效预算进入准备界面，不再后台请求高清图；桌面设备才在空闲时补载高清资源。顶栏保留紧凑的剩余预算与 1×/2×/4× 速度控制；`index.html` 是可直接双击运行、也可直接部署到 GitHub Pages 的静态入口。
